# 🤖 Hand Gesture Controlled Bluetooth Car

A fun and interactive Arduino-based robotics project that uses hand gestures captured by a laptop webcam to control a car via Bluetooth. This combines computer vision (MediaPipe + OpenCV) with embedded systems to create a gesture-controlled vehicle.

## 🚗 Features

* Control car movement (Forward, Backward, Left, Right) using **hand gestures**
* Uses **MediaPipe** and **OpenCV** to detect hand gestures via webcam
* Bluetooth communication with Arduino via **HC-06**
* Compatible with any laptop having a webcam and Python installed

---

## 🧰 Hardware Components

* Arduino UNO
* L293D Motor Driver Shield
* HC-06 Bluetooth Module
* 4 DC Motors
* 4 × 1.5V AA Batteries and holder
* Chassis, Wheels, Jumper wires
